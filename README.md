# کافه نو

وب‌سایت فارسی، راست‌چین و responsive کافه نو با Laravel 13، PHP 8.4 و Blade. این نسخه عمداً بدون Vite، Next.js یا build step جاوااسکریپت ساخته شده و استایل‌ها در `public/css/app.css` قرار دارند.

## مسیرها

- `/` خانه
- `/menu` منوی کافه
- `/about` درباره ما
- `/contact` تماس با ما و نقشه میدان امام حسین
- `/shipping` شیوه ارسال
- `/tax` قوانین و مالیات
- `/admin` نمای اولیه پنل مدیریت

## تحلیل رقبا و تصمیم طراحی

بررسی نمونه‌های کوکافه، منودار، لوتوس منو، رستیو و صفحات خدمات طراحی سایت رستوران نشان داد که منوی سریع موبایلی، قیمت شفاف، ساعت کاری، آدرس/نقشه و سفارش بیرون‌بر مهم‌ترین نیازها هستند. کافه نو برای تمایز از ظاهرهای تکراری، از هویت تیره‌سبز و مسی، تایپوگرافی فارسی خوانا، کارت‌های خلوت و CTA مستقیم استفاده می‌کند.

## اجرا

این فایل‌ها را داخل یک نصب استاندارد Laravel 13 قرار دهید و `php artisan serve` را اجرا کنید. هیچ `vite.config.*` یا `resources/js` برای این تجربه استفاده نشده است.
