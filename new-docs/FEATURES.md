# کافه نو — مستندات امکانات

## بخش عمومی

خانه، منو، جزئیات غذا، دسته‌بندی، جست‌وجو، سبد سفارش، سفارش حضوری/بیرون‌بر/ارسال، درباره ما، گالری، تماس، نقشه، شیوه ارسال، مالیات، رزرو میز و رزرو جشن و تولد.

## پنل مدیریت

داشبورد فروش، سفارش‌های زنده، تابلو آشپزخانه، سالن و میزها، رزروها، مراسم، منو و دسته‌بندی، افزودنی‌ها، موجودی، گالری، مشتریان، تخفیف، باشگاه مشتریان، مناطق ارسال، مالیات، گزارش‌ها، کاربران و نقش‌ها، تنظیمات و لاگ فعالیت.

## وضعیت سفارش

new، accepted، preparing، ready، dispatched، delivered، cancelled و refunded. کانال‌های dine-in، takeaway و delivery پشتیبانی می‌شوند.

## Seeder

`php artisan migrate --seed` دسته‌بندی‌ها، غذاهای ایرانی و بین‌المللی، نوشیدنی‌ها، دسرها، میزها و محدوده‌های ارسال را با تصاویر متفاوت ساخته و آماده استفاده می‌کند.

## مسیرهای اصلی

`/`، `/menu`، `/about`، `/contact`، `/shipping`، `/tax` و `/admin`.

این نسخه بدون Vite و Next.js طراحی شده است. برای production احراز هویت Laravel، درگاه پرداخت، پیامک و اتصال نقشه باید با سرویس انتخابی پروژه پیکربندی شوند.
